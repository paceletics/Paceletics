# Publish Paceletics Beta with GitHub Pages

This repository is the standalone Paceletics web beta project.

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Click **Save**.
6. Wait for the Pages deployment to complete.
7. GitHub will show the beta website address.

The beta includes `noindex` and `robots.txt` rules to discourage search engines from indexing it.

## Important
The current beta stores data in the browser only. Do not use it as the only copy of important athlete data. Export backups while testing.

## Next production step
