Paceletics Beta

This website is an early testing version of the Paceletics Coach Dashboard.

← Back to dashboard

What works now

Athlete management, PBs, session building, effort-based targets, group assignment, weekly calendar, results, stats, local backup/import and a simulated Android sync queue.

What is not live yet

Accounts, a cloud database and automatic Android sync are not connected in this beta. Data is stored in the browser you are using unless you export a backup.

Beta testing

Do not rely on the beta as the only copy of important athlete data. Export a backup regularly while testing.
