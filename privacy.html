Paceletics Beta Privacy Notice

← Back to dashboard

This beta version does not send athlete, session or result data to a Paceletics cloud server. Data entered into the dashboard is stored locally in the web browser using browser storage.

The Export feature creates a JSON backup file on the user's device. Anyone with access to that file may be able to read the data it contains, so testers should keep backups secure.

Before a public production launch, Paceletics will require a full privacy policy covering accounts, cloud storage, analytics, data retention and deletion.
