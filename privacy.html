Paceletics Beta Privacy Notice

← Back to Paceletics

Paceletics Beta uses Supabase for account authentication. When you create or use an account, authentication information such as your email address, account identifier and account type is processed through the connected Supabase project.

At this beta stage, athlete profiles, training sessions and result data created inside the dashboard are still stored locally in the web browser and are not yet saved to the Paceletics cloud database.

The Export feature creates a JSON backup file on the user's device. Anyone with access to that file may be able to read the data it contains, so testers should keep backups secure.

Before production launch, this notice will be expanded to cover cloud storage, retention, deletion, account controls and any analytics or support services used by Paceletics.
