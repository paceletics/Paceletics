# Paceletics Web Beta Project

This is a standalone project for the Paceletics web dashboard beta.

It is intentionally separate from the Android app project.

## Project purpose
- Coach dashboard
- Athlete roster and PB management
- Session Builder
- Effort-based personalised targets
- Group assignments
- Weekly calendar
- Results and stats
- Beta backup/import
- Simulated Android sync

## Current limitation
This beta uses local browser storage only.
Live Android/web sync will require accounts and a shared cloud database.
