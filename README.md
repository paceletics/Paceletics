# Paceletics Beta Website v0.2

Deployable static beta of the Paceletics Coach Dashboard.

## Included
- Dashboard
- Athlete roster and PB management
- Session Builder
- Effort-based personalised target preview
- Group session assignments
- 7-day calendar
- Results and statistics
- Simulated Android sync queue
- JSON backup and restore
- Demo reset / empty beta
- Responsive mobile layout
- PWA manifest and service worker
- Beta privacy/information pages
- GitHub Pages-ready files

## Important beta limitation
There is no cloud backend yet. Data is stored in each tester's browser. Android sync is simulated.

## Local test
Open `index.html`.
